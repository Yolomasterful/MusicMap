#MusicMap

A single-page React app that maps MusicBrainz artists and albums to their
equivalents on Deezer (and optionally Qobuz). No build tools, no `npm install`.

## Run it

The app uses `fetch()`, which requires an HTTP server (opening `index.html`
directly won't work because of CORS). Any of these will do:

## Running Web
Running either
`make`
*or*
`npm install && npm start`
